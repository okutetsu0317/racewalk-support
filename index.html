競歩ラボ

競歩ラボ サポート

競歩ラボは、競歩動画を見ながら接地・離地フレームを記録し、接地時間、滞空時間、左右差、速度との関係を確認するためのiOSアプリです。

使い方

  • 「測定」タブで新規測定を作成します。
  • 動画を選択するか、アプリ内で撮影します。動画なしで手入力もできます。
  • 測定画面で左右2歩ずつ、接地・離地の8イベントを記録します。
  • 測定完了後、詳細画面と分析画面でグラフを確認します。

App Review用サンプル動画

分析機能の確認用に、アプリへ取り込める競歩動画と、実際の測定操作・分析表示を確認できるデモ動画を公開しています。

  • 入力用サンプル動画 sample_racewalk.MP4 をダウンロード（約5秒・30fps）
  • 最新版UIでの実操作デモを見る（M4V）
  • 分析タブ確認デモを見る（MP4）

For App Review: Download the sample MP4 and import it when creating a measurement. The latest workflow demo shows frame-by-frame playback, eight contact/takeoff records, completion, and calculated results. The analysis demo shows the completed-measurement chart.

データの扱い

初期版では、測定データと動画ファイルは端末内に保存されます。ログイン、外部サーバー通信、広告SDK、解析SDKは使用していません。

注意事項

本アプリはコーチや選手が動画確認を補助するためのツールです。AI判定、姿勢推定、公式競技判定の代替は行いません。
